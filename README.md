### 👨‍💻 Executive Summary & About Me

I am a **Principal Software Architect & Full-Stack Systems Engineer** with extensive experience leading end-to-end development, containerized cloud infrastructure, and mission-critical integrations. 

- 🏢 **Founder & Lead Architect** at [Software House](https://www.softwarehouseworld.com), delivering enterprise-grade platforms across FinTech, ERP automation, logistics, and mobile ecosystems.
- ⚡ **Core Focus**: High-concurrency web systems, hybrid mobile apps (Expo/React Native), TallyPrime XML-RPC middleware pipelines, and automated zero-downtime CI/CD deployments.
- 🛠️ **DevOps & Cloud**: Orchestrating multi-container Linux VPS environments, Nginx Reverse Proxy routing, Docker Swarm/Compose architectures, and automated GitHub Actions workflows.
- 🧠 **AI/ML Focus**: Practical GenAI integrations, agentic workflows, and automated pipeline intelligence.
- 🤝 **Collaboration**: Open to technical leadership roles, enterprise consulting, and high-impact distributed architecture builds.
